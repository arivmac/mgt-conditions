# MGT Conditions

Runner-reported conditions for Toronto's Martin Goodman Trail: ice, slush,
hazards, wind and the best time to run. Built with
[Mast for Astro](https://github.com/CoreyMoen/mast-astro) (MIT), edited in
[Stacki](https://github.com/flowtricks/stacki).

- Project brief, design and phases: [`docs/PROJECT.md`](docs/PROJECT.md)
- Working prototype to match: [`reference/prototype.html`](reference/prototype.html)
  (open it in a browser; reports won't save outside the hosted version)

## Run it

Requires Node 22.12+.

```sh
npm install
npm run dev     # http://localhost:4321
npm run check   # must stay at 0 errors
npm run build
```

Or open this folder in Stacki, which runs `astro dev` for you.
